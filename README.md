# Machine Learning & Mathematics — Learning From Scratch

This repository documents my journey of learning **Machine Learning, Mathematics, and Neural Networks** through hands-on coding and experimentation.

My goal is to understand not just how to use machine learning models, but **how and why they work internally**, including the mathematics behind them.

## 📂 Repository Contents

### 1. `intro_to_ML_and_math_behind_ML.ipynb`

This notebook contains coding exercises and practical examples based on the Machine Learning and Mathematics books I am currently studying.

**Focus areas:**
- Understanding mathematical concepts behind machine learning.
- Practising examples and exercises from textbooks.
- Implementing mathematical concepts using Python.
- Connecting mathematical theory with practical ML applications.

### 2. `neural_and_MLmodel_with_numpy.ipynb`

This notebook focuses on building Machine Learning and Neural Network models from scratch using **plain Python and NumPy**, without depending on high-level ML frameworks.

**Focus areas:**
- Implementing simple machine learning models.
- Understanding weights, biases, and model parameters.
- Exploring forward propagation and mathematical computations.
- Learning how models make predictions and improve through training.
- Understanding the fundamental building blocks of neural networks.
